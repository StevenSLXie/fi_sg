# 记账不是做账

> **导航：** [← 第二章：两个毕业生，一张表](chapter-02.md) · [目录（英文）](../SUMMARY.md) · [第四章：4% 到底是什么 →](chapter-04.md)

记账不难，难在坚持。

很多家庭第一次记账，开头都很认真。下载一个 app，每一杯咖啡、每一顿午饭、每一次网购都单独归类。前两周很有成就感，第三周开始漏，第四周开始补，三个月之后 app 还在手机里，但已经和跑步机差不多，只负责提醒你曾经有过一个计划。

失败的原因通常不是懒。很多时候，是做得太复杂。一个家庭要追踪 FI，不需要在家里开一家小会计师事务所。每个小吃、每张收据、每一次超市付款都拆成十几个类目，最后只会得到很多图表，以及很少的判断。

第二章说，储蓄率是最值得看的单一数字。但数字要有用，前提是量得诚实。对一个普通家庭来说，需要盯住的东西其实不多：收入、开支、CPF、房贷本金和利息、资产余额，以及 FI 进度。

我的原则很简单：会改变 FI 算法的地方，要分清楚；不会改变判断的地方，粗一点没关系。

## App 不是重点

我自己用的是 Money Manager，但 app 不是重点。表格可以，别的记账软件也可以。工具只要做到一件事就够了：减少阻力。它要能记录收入、支出、账户、资产和负债，也要能按月、按年看大类目。除此之外，功能越多，不一定越好。

真正要紧的是类目怎么设，不是用哪个 app。

类目太细，坚持不下去；类目太粗，看不出问题。类目的作用不是让账本看起来专业，而是让家庭能做决定。

下面是我自己的一个简化版本，不是标准答案：

| 类目 | 包括什么 | 为什么单独列 |
|---|---|---|
| 房贷本金 | 房贷月供里的本金部分 | 储蓄 / 净值增加 |
| 房贷利息 | 房贷月供里的利息部分 | 真正的住房开支 |
| 税 | 个税、房产税等 | 大额、但不是每月发生 |
| 学校 | 幼儿园、学校费用、和孩子教育有关的经常性开支 | 养娃里的固定项目 |
| 超市和日用品 | 买菜、日用品、小额家庭采购 | 日常消费大头 |
| 女佣 | 工资、levy、相关费用 | 家庭后勤成本 |
| 车 | 油费、停车、维修、路税、保险等 | 交通固定成本 |
| 公共交通 | MRT、巴士、打车、网约车 | 交通变动成本 |
| 水电网电话 | 水电、宽带、手机 | 基础账单 |
| 保险 | 医疗、人寿、房屋、车险等 | 风险转移 |
| 医疗 | 看诊、牙医、药 | 健康开支 |
| 小贩中心 / 食阁 / 外卖 | hawker、kopitiam、工作日外卖 | 便宜且高频的外食 |
| 餐厅 | 有服务费的餐厅、咖啡馆、庆祝性用餐 | 和 hawker 不是同一种产品 |
| 旅行 | 机票、酒店、探亲、旅行 | 旅行和家庭连接 |
| 娱乐 | 订阅、出游、休闲 | 可选开支 |
| 其他 | 不值得单独开类目的东西 | 保持系统简单 |

这里最重要的类目，可能反而是“其他”。

总会有一些开支，不值得单独开一个类目。如果每出现一笔奇怪交易，就新建一个分类，最后会多出一堆一年只用一次的类目。“其他”这个口子留着，账本反而更容易活下来。

## 类目可以粗一点

我把超市、日用品、Watsons 之类的东西放在一起，不是说它们完全一样。问题是分开以后，也不一定能改变决策。

记账时真正要问的是，这笔钱服务了什么家庭功能。买菜、纸巾、洗衣液、牙膏，本质上都是日常家庭消耗。除非你真的要专门优化药妆店开支，否则把它们拆得很细，只是在增加工作量。

类目要足够粗，才能坚持；也要足够细，才能看出问题。这个平衡没有标准答案，只有一个简单测试：这个类目会不会改变你的决定？

会，就单独列。不会，就合并。

## 新加坡家庭有几个特别容易算错的地方

第二章讲过两个最重要的拆分。

第一，CPF 是财富，但不能当现金用。员工 CPF 和雇主 CPF 都在增加家庭资产负债表，只是明天买菜用不上。

第二，房贷要拆成本金和利息。本金偿还是在增加房屋净值、减少负债；利息才是付给银行的成本。银行每年的 housing loan statement 已经把这件事拆好了，只是很多人记账时又把它们混回去。

除此之外，还有三项很容易被低估。

第一是税。新加坡个税税率不高，但金额未必小。对中高收入家庭来说，个税可能是年度大项，而且一旦不工作，这项开支会明显下降。如果把税混在一般开支里，退休后的开支会被算高。

第二是学校。SingStat 2023 年 Household Expenditure Survey 里，平均家庭每月教育开支约 S$404，其中 private tuition 平均约 S$105。[1](#note-1) 有孩子当然会多花钱，但只问“孩子贵不贵”没有太大用。要拆开看：公立体系的基本费用是多少，补习、enrichment、私校替代是多少，家长焦虑又变成了多少每月账单。

第三是吃饭。新加坡的外食，其实不是一种东西。买菜做饭、小贩中心、食阁、外卖、餐厅，都叫吃饭，但价格和功能完全不同。一个“dining”类目会把日常解决方案和周末消费混在一起。

## 尽量留下痕迹

我的大部分账，都来自银行和信用卡流水。所以有一个很实用的原则：能留下记录，就尽量留下记录。

现金不是不能用，只是不好追踪。现金花多了，要么靠人手补，要么靠记忆。问题是靠记忆记账，最后通常会少算。

在新加坡，这件事相对容易。信用卡、PayNow、GIRO、银行转账，已经覆盖了大部分家庭开支。剩下的现金，主要是小贩中心、wet market 和少数小店。这部分不用逐笔记，可以设一个每周现金预算，月底估算。

记账不是为了精确到小数点后两位。它是为了不要骗自己。

## 不要看单月

单月开支噪音很大。

这个月有奖金，下个月有房产税，再下个月有旅行，之后又有学校费用。拿四月和三月比，然后说家庭财务进步了或者退步了，多半是在比较账单发生的时间，不是在比较真实生活。

我建议看 12 个月滑动平均。

比如 2025 年 6 月到 2026 年 5 月，是一组 12 个月开支；下个月就变成 2025 年 7 月到 2026 年 6 月。每个月拿掉最旧的一个月，加上最新的一个月。这个数字变化慢，正因为它变化慢，才有用。

很多年度账单、一次性开支、旅行和学校费用，都会被平滑掉。家庭才不会因为一个月的账单，突然以为自己变富或者变穷。

前提是类目要稳定。今年的旅行类目，明年还要叫旅行。今天把餐厅归到“娱乐”，明天又归到“食物”，图表就只是装饰。

## 一个真实家庭的样子

用一户家庭的账本，不是让别人照抄。真实账本能说明平均数看不出来的东西。

2025 年，我家年度开支里最大的四项，是房贷利息、旅行、税和学校。四项合起来，接近全年开支的一半。超市和日用品这种最有“每天花钱”感觉的类目，反而不到 7%。餐厅和娱乐，在房贷和 IRAS 面前，基本不是主角。[2](#note-2)

| 类目 | 年度开支占比 |
|---|---:|
| 房贷利息 | 13.9% |
| 旅行 | 12.1% |
| 税 | 11.6% |
| 学校 | 11.3% |
| 房贷本金 | 11.2% |
| 其他 | 9.5% |
| 超市和日用品 | 6.8% |
| 保险 | 5.1% |
| 水电网电话 | 3.3% |
| 车 | 2.9% |

不要照抄这些比例。我的旅行里有不少是回国探亲，对我来说更接近家庭义务，不完全是度假。我家的车这一项低，是因为没有车。别的家庭会完全不同，正是因为生活不同。

作为对照，SingStat 的 HES 2023 显示，新加坡 resident household 平均每月开支是 S$5,931；如果把自住房的 imputed rent 算进去，是 S$7,119。按后一种算法，住房、食物和交通合计占 63.2%。[1](#note-1)

这个形状和我家很不一样，也很可能和你家不一样。

所以记账的价值在这里：先看见自己的家庭。看不见之前，买房、买车、学校、旅行这些决定，都在和一个想象中的“普通家庭”比较。

## 收入和资产也要一起看

很多人开始记账，只记支出。这可以理解，因为支出最有感觉，也最像可以控制的东西。

但 FI 不能只看支出，还要看收入、储蓄和资产之间的关系。只记支出，就算不出储蓄率，只能对某些消费感到高兴或者内疚。

我的收入类目很简单：工资、CPF 供款、股息、SSB 派息、银行利息、其他。CPF 要放进来，因为它是家庭储蓄流的一部分。

被动收入也值得跟踪，但不要太迷信。股息、利息、租金如果已经覆盖年度开支，当然很直观，尤其适合偏股息或 fixed income 的家庭。但如果你主要投的是全球指数，股息可能不高，资产增值却不错。反过来，一个高股息组合看起来现金流很好，长期增长未必更有效率。

被动收入是一个有用数字，只是不能只看它。

还要看资产。最基本的家庭表，至少要看这几项：

| 项目 | 频率 | 用途 |
|---|---|---|
| 收入和支出 | 每月 | 计算储蓄率 |
| CPF 供款 | 每月 / 每年 | 算进强制储蓄 |
| 房贷本金和利息 | 按年度 statement 分拆到每月 | 把储蓄和费用分开 |
| 12 个月滑动开支 | 每月 | 平滑年度账单和一次性开支 |
| 现金、CPF、投资余额 | 每月或每季 | 看流动性、锁定财富和复利资产 |
| 净资产和 FI 分子（FI numerator） | 每月或每季 | 区分总财富和能支持 FI 的资产 |

这已经够了。做生意、多套房、收入不稳定的家庭，可能需要更多。大多数受薪家庭真正的问题，是表格复杂到三个月后没人想碰。

银行余额、CPF 余额这些数字，本来就会自己出现。比较麻烦的是投资组合和自住房。

投资组合可以每季按市价更新。每天看没有意义。家庭看投资组合，是为了知道 FI 分子有没有往前走，不是为了交易。

自住房更麻烦。最简单的做法是完全不算，但这也太粗。自住房不产生现金流，不能拿来日常提款；但它的市场价值仍然重要。一个家庭如果降级住房、卖房租房，或者搬去更低成本的地方，房子确实可以释放现金。

我的折中办法是两个数字。

房子每年估一次价值，参考同楼盘成交、SRX 或 EdgeProp 估价就够了，放进 net worth。另一个数字叫 FI 分子（FI numerator），只看真正能支持 FI 的资产，通常先排除自住房：

`FI numerator x withdrawal rate / annual spending`

如果这个比例是 50%，意思是投资组合按你选的提款率，理论上能支持家庭一半年度开支。如果到 100%，工资就变成可选项。

net worth 告诉你有多少财富。FI 分子告诉你，能不能靠这些资产撑起生活。追求 FI 的家庭，两者都要看。下一章会正式讲这个分子。

至于 withdrawal rate 到底该用 4%、3.5% 还是别的数字，是下一章的问题。记账这一章先做更基础的事：把分子和分母量清楚。不然讨论提款率，只是在空中吵架。

## 真正执行时，越简单越好

如果希望这个系统三年后还在，而不是三周后就死掉，可以先遵守几条规则。

第一，每月记一次，不要每笔都记。每买一杯咖啡就录入一次，听起来很认真，实际很容易死。银行、信用卡、CPF、券商已经帮你记录了大部分数据。你的工作是每月花半小时到一小时，把它们归类。

第二，先回填一年。把去年一整年的银行和信用卡流水拉出来，一两次做完。这样第一天就有一个 12 个月基线，而不是等一年以后才知道家庭到底花多少钱。

第三，类目要少到自己能背出来。十五到二十个大类已经够多。如果不看表都想不起类目，说明系统已经太复杂。

第四，只比较 12 个月数字。相邻两个月一定很戏剧化，但大部分戏剧都是时间差。看长期数字，不要看噪音。

第五，每月和资产负债表对一下。收入减支出，大致应该解释资产减负债的变化。如果对不上，通常是 CPF 流、账户转账、信用卡还款重复计算，或者某笔钱漏了。这个检查不需要审计每一笔交易，但能防止系统自欺欺人。

第六，AI 以后可以帮忙做杂活。读 statement、识别商户、归类、找异常交易，这些都适合让 LLM 处理导出的 CSV。但一开始最好手动做一阵，因为你要先知道哪些类目对自己家庭真的重要。AI 可以帮你抄账，不能替你决定家庭该看什么。

## 诚实就够了

记账不是为了让家庭内疚，而是为了让家庭看得见自己。

一旦看得见，很多争论就会变具体。要不要买车？先看交通。公寓是不是拖慢 FI？先把贷款成本和资产分开。孩子是不是让 FI 不可能？先看学校线和 12 个月开支。投资够不够？看储蓄率和 FI 分子。

表格、app、AI 工具都不会替你做决定。它们只是让取舍更难被藏起来。

家庭不需要完美会计。它需要的是足够诚实、能够改变决策，而且简单到能坚持下去的记账。
